# IPv6 Addressing and Configuration Lab

This project demonstrates the implementation and verification of IPv6 networking concepts using Cisco Packet Tracer. The lab focuses on configuring Global Unicast Addresses (GUA), Link-Local Addresses, enabling IPv6 routing, and testing connectivity between multiple IPv6 networks. It also explores Neighbor Discovery Protocol (NDP), ICMPv6 communication, and the differences between routable and non-routable IPv6 addresses while reinforcing key CCNA networking concepts.
