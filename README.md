# CCNA Packet Tracer Labs

This repository contains a collection of hands-on networking labs completed using Cisco Packet Tracer while studying Cisco CCNA concepts. The projects cover routing, switching, IPv4 and IPv6 networking, NAT, ACLs, wireless networking, and network troubleshooting.

## Repository Organization

Each topic is organized into a dedicated folder containing:

- Packet Tracer project files (`.pkt`)
- Network topology screenshots
- Supporting notes and documentation

## Important

The topology screenshots provide a visual overview of each lab; however, they do not contain the complete project details.

To fully understand each implementation, please open the associated `.pkt` file in Cisco Packet Tracer. Every Packet Tracer project includes configuration notes, command summaries, explanations of the concepts covered, and a step-by-step overview of the work performed during the lab.

## Topics Covered

- EtherChannel
- IPv6 Addressing and Configuration
- DHCP
- NAT
- OSPF
- ACLs (Standard, Extended, Numbered, and Named)
- Multilayer Switching
- DTP and VTP
- Wireless LAN Controllers and Access Points
- ISP Connectivity and Routing

## Purpose

This repository showcases practical CCNA networking experience through real-world configuration, verification, and troubleshooting scenarios using Cisco Packet Tracer and Cisco IOS.
